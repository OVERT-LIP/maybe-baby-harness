# 🎀 МЕЙБИ БЕЙБИ ХАРНЕСС ♡

Максимально девчачья обёртка для [OpenCode Web](https://opencode.ai), вдохновлённая Hannah Montana Linux и эстетикой Y2K.

> Компилирую на блёстках. Дебажу лапками. Деплою с бантиком.

## Что внутри

- Светлая тема «Принцесса» и тёмная «Суперзвезда».
- Котики с бантиками, бантики, сердечки и бриллианты.
- Всплывающие сердечки на фоне, блёстки за курсором и взрыв блёсток при клике.
- Хромированный стикер **MAYBE BABY** и курсор-леденец.
- **💿 MAYBE BABY POD** — Y2K MP3-плеер с тремя оригинальными 8-битными треками через Web Audio.
- Переключатель «💎 Глиттер-апокалипсис» в меню оформления (иконка солнца/луны внизу сайдбара).
- Уважает `prefers-reduced-motion`.

Весь функционал базового скина сохраняется: сайдбар с тредами по проектам, поиск, закрепление, архив, уведомления, счётчик токенов, индикатор генерации, создание проектов, SSE и терминал.

## Запуск (Windows)

Нужны [Node.js](https://nodejs.org) и `opencode` в `PATH` (`npm i -g opencode-ai`).

```cmd
start.cmd
```

Откроется http://127.0.0.1:4098.

Цепочка:

```
браузер → Maybe Baby (4098) → Codex skin (4097) → opencode serve (4096)
```

- `server.js`, `hannah.js`, `hannah.css`, `icon.svg` — слой МЕЙБИ БЕЙБИ.
- `vendor/codex-web/` — базовый Codex-скин, который добавляет сайдбар, токены и остальную логику.

Вручную:

```cmd
opencode serve --port 4096 --hostname 127.0.0.1
node vendor\codex-web\server.js
node server.js
```

Порты меняются переменными `HANNAH_PORT`, `HANNAH_UPSTREAM_PORT`, `OC_SKIN_PORT`, `OC_UPSTREAM_PORT`.

CSS и JS читаются с диска на каждый запрос — после правок достаточно обновить страницу.

## Безопасность

Все серверы слушают только `127.0.0.1`. Не выставляйте их в сеть: через OpenCode можно выполнять команды на компьютере.
